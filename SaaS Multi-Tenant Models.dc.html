เริ่มที่ Pooled เป็นค่าเริ่มต้น + เปิด Siloed (DB-per-tenant) เป็นแพ็กเกจ Enterprise

ERP เป็นข้อมูลอ่อนไหว (บัญชี/HR/ลูกค้า) ลูกค้าองค์กรมักต้องการการแยกข้อมูลระดับสูงและ compliance — โมเดลผสมจึงตอบได้ทั้งต้นทุนและความเชื่อมั่น:

  • ลูกค้าเล็ก–กลาง → Pooled: DB เดียว + tenant_id บนตารางที่ผู้เช่าเป็นเจ้าของ + Row-Level Security คุ้มต้นทุนและ scale ง่าย
  • ลูกค้าใหญ่ / ต้องการ isolation → Siloed: แยก DB/instance ต่อราย ปรับแต่งและ SLA รายลูกค้าได้
  • Master กลาง (ประเทศ/จังหวัด/อำเภอ/ตำบล) → platform-global เสมอ: ไม่ต้องมี tenant_id ใช้ร่วมได้ทุกผู้เช่า
  • สถานะปัจจุบันของ Mee-ERP OS = Siloed (Single-Tenant): ขอบเขตข้อมูลคือ company_id, tenant anchor ที่ตาราง company — ถ้าจะไป Pooled ค่อยเพิ่ม tenant_id (nullable = global) เฉพาะตารางที่ผู้เช่าเป็นเจ้าของ แล้ว stamp/resolve อัตโนมัติตอน push/pull (แพทเทิร์นเดียวกับ company_id) โดยไม่แตะ geo/master
